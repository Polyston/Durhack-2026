## How to publish

1. Create a free account at [dev.to](https://dev.to).
2. **Create Post → switch to the Markdown editor**, and paste a file's contents (the `--- ... ---` front matter at the top sets the title, tags and description automatically).
3. Add a **cover image** (a screenshot of the app works well) in the `cover_image:` field or the editor.
4. Fill in the repo and live-demo links where each post says *"in the comments"*, or inline.
5. Set `published: false` → `true` when you're ready, and publish.

The challenge rewards technical substance, originality and clear storytelling, so each post leads with the problem, shows one or two real technical decisions, and is honest about limitations. Edit freely before publishing — add your names and a screenshot or two.
